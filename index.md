## 🛠️ How to Install (It's Easier Than You Think)

**You don't actually "install" doom_epub like a normal program.** Since it's an EPUB file, it works with any compatible ebook reader. Here's how to get it running on Windows:

### Step 1: Find the Downloaded File

Open your **File Explorer** (the folder icon on your taskbar) and go to your **Downloads** folder. You should see the `doom_epub` file there.

### Step 2: Open It With an Ebook Reader

- **Option A (Recommended for beginners):** If you have **Microsoft Edge** (which comes with Windows 10/11), simply right-click the file, select **"Open with"**, and choose **Microsoft Edge**. Edge has a built-in EPUB reader that works perfectly.
- **Option B:** If you use **Calibre** (a free ebook manager), open Calibre, click **"Add books"**, select your file, and then double-click it to open.
- **Option C:** If you have **Apple Books** installed on your Windows machine, drag the file into the Apple Books library window.

### Step 3: Start Playing!

Once the file opens, you'll see the classic DOOM title screen. Use your **arrow keys** or **WASD** keys to move, **mouse** to look around, and **spacebar** to shoot. The game runs entirely inside the ebook reader — no plugins, no internet connection needed after download.

## 🎯 Frequently Asked Questions

### ❓ Why doesn't it run like a normal game?
Because it's an EPUB file — it's designed to be read by ebook software. The magic is that the game code is embedded inside, so the reader runs it for you. That's why it's so portable.

### ❓ Will it work on my Kindle?
Kindles are picky about EPUB files. Some newer Kindle models support EPUB, but older ones might not. We recommend trying it on your Windows computer first with any reader that handles EPUB well.

### ❓ Do I need internet after downloading?
No! Once the file is on your computer, the game is 100% offline. It's all in the file.

### ❓ Is this the full version of DOOM?
This is the **shareware episode** — the first 9 levels. It's the same content that millions played for free back in 1993. The full game had three episodes; this gives you the first one.

### ❓ I double-clicked it and nothing happened. Help!
Make sure your default app for EPUB files is set to an ebook reader. If you don't have one, download **Calibre** (free from calibre-ebook.com), install it, then right-click the file → **Open with** → **Calibre**.
